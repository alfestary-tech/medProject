# Alfestary DICOM Viewer

Проект для просмотра DICOM-срезов КТ и подготовки данных лучевой терапии. Графическое приложение позволяет выбрать папку со срезами, посмотреть изображения и данные пациента. Отдельные модули читают КТ, контуры структур (RTSTRUCT), дозу (RTDOSE) и план лечения (RTPLAN). Обучения модели и создания нового плана в проекте пока нет.

## Что реализовано

- **Просмотр DICOM:** список срезов из выбранной папки, основной срез, виды спереди и сбоку, слайдер для перехода между срезами. Белая линия на дополнительных видах отмечает уровень выбранного среза.
- **Данные пациента:** имя, ID, дата рождения и тип исследования из открытого DICOM-файла.
- **Аккаунты:** регистрация, вход и выход. Пароли хранятся в виде хешей Argon2, данные аккаунтов и история выбора папок — в SQLite (`data/main.db`). Сессия прекращается после трёх календарных дней без обновления даты последнего использования.
- **КТ (`CT`):** для отдельной обработки срезы сортируются по координате, дубликаты удаляются по `SOPInstanceUID`, значения пикселей переводятся через `RescaleSlope` и `RescaleIntercept`.
- **Контуры (`RTSTRUCT`):** контуры сопоставляются со срезами КТ по `SOPInstanceUID`. Маски ROI строятся с помощью OpenCV; также есть вариант построения через scikit-image для сравнения.
- **Доза (`RTDOSE`):** чтение карты дозы и DVH, перенос дозы на сетку КТ с линейной интерполяцией.
- **План (`RTPLAN`):** чтение дозовых ориентиров, групп фракций, пучков и контрольных точек.

Просмотр в `main.py` и подготовка данных в `parser/` сейчас работают отдельно: графический интерфейс не запускает `prepare_all_data()`.

## Установка и запуск

Установите зависимости из `requirements.txt`. Запускайте команды **из корня проекта**: приложение открывает `data/main.db` по относительному пути.

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows (PowerShell):

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

После запуска зарегистрируйте аккаунт или войдите в существующий. В основном окне выберите **Файл → Открыть папку** и укажите каталог со срезами DICOM. Файлы должны лежать непосредственно в выбранном каталоге и содержать `InstanceNumber`: по нему строится порядок срезов. Переходить между ними можно слайдером или через список справа. Кнопка «Папка» показывает путь в строке состояния, «Выход» завершает текущую сессию.

Виды спереди и сбоку собираются из центральной строки и центрального столбца каждого среза соответственно. Для их построения размеры всех срезов в папке должны совпадать. Эти виды используются для навигации и не являются геометрической реконструкцией по координатам DICOM.

## Подготовка КТ, контуров, дозы и плана

Для отдельной обработки нужен каталог КТ и файлы RTSTRUCT, RTDOSE и RTPLAN. Пути передаются функции `prepare_all_data()`; менять их в `main.py` не требуется. Пример структуры входных данных:

```text
datasets/Patient01/
├── CT/                 # DICOM-файлы срезов
├── RS.dcm              # RTSTRUCT
├── RD.dcm              # RTDOSE
└── RP.dcm              # RTPLAN
```

```python
from parser.parser import prepare_all_data

cts, masks, dose_on_ct, info = prepare_all_data(
    ct_dir="datasets/Patient01/CT",
    counters_filename="datasets/Patient01/RS.dcm",
    dose_filename="datasets/Patient01/RD.dcm",
    plan_filename="datasets/Patient01/RP.dcm",
)
```

| Результат | Содержимое | Форма |
| --- | --- | --- |
| `cts` | КТ после применения коэффициентов масштабирования. | `(Z, H, W)` |
| `masks` | Булевы маски ROI на сетке КТ. | `(Z, R, H, W)` |
| `dose_on_ct` | Доза, перенесённая на сетку КТ. | `(Z, H, W)` |
| `info` | Словарь метаданных КТ, ROI, дозы и плана. | — |

`Z` — число срезов, `R` — число ROI, `H` и `W` — высота и ширина среза. В `info["roi_channels"]` каждому каналу маски сопоставлены номер и название ROI. При общей обработке проверяется серия RTSTRUCT, единый `FrameOfReferenceUID` КТ и совпадение UID системы координат с RTDOSE и RTPLAN. Области КТ вне дозовой сетки получают нулевую дозу. `dose.resize()` также создаёт `valid_mask`, но `prepare_all_data()` сейчас её не возвращает.

Функция возвращает данные в памяти и ничего не сохраняет. Чтобы записать КТ и маски в `.npz`, а сведения о срезах и ROI в `.json`, вызовите функции сохранения отдельно:

```python
from parser import counter, scan
from parser.parser import save_ct_and_masks, save_info_json

cts, ct_info = scan.prepeare_CT_images("datasets/Patient01/CT")
counter.open_conture_dicom("datasets/Patient01/RS.dcm", ct_info)
masks = counter.collect_masks(cts, ct_info)

save_ct_and_masks(cts, masks, "output/Patient01_ct_masks.npz")
save_info_json(ct_info, "output/Patient01_info.json")
```

Здесь `save_info_json()` получает именно список `ct_info` из `scan.prepeare_CT_images()`, а не итоговый словарь `info` из `prepare_all_data()`.
